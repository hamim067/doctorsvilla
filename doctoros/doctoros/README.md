# DoctorOS — MVP (ধাপ ১)

ডাক্তারের প্রোফাইল, অনলাইন সিরিয়াল, অ্যাসিস্ট্যান্টের সিরিয়াল কিউ, রোগীর লাইভ ট্র্যাকিং, প্রেসক্রিপশন আর অটোমেটিক ফলোআপ।

**প্রযুক্তি:** Next.js 15 (App Router, React 19, TypeScript) · PostgreSQL · Drizzle ORM · Server Actions · Vercel Cron

## চালু করা (ডেভেলপারের জন্য)

```bash
npm install
cp .env.example .env          # DATABASE_URL আর SESSION_SECRET বসান
npm run db:migrate            # টেবিল তৈরি
npm run db:seed               # ডেমো ডেটা (ঐচ্ছিক)
npm run dev                   # http://localhost:3000
```

ডেমো লগইন (seed চালালে) — ডাক্তার: `01700000001` / `demo1234` · অ্যাসিস্ট্যান্ট: `01700000002` / `demo1234` · প্রোফাইল: `/dr/dr-tanvir`

স্কিমা বদলালে: `src/db/schema.ts` এডিট → `npm run db:generate` → `npm run db:migrate`

## ডেমো অ্যাকাউন্ট (লাইভ সাইটেও তৈরি হয়)

প্রতিবার build-এর সময় `src/db/demo.ts` চলে — ডুপ্লিকেট হয় না, আর প্রতিদিনের প্রথম build-এ ডেমো চেম্বারে "আজকের" সিরিয়াল তৈরি হয়।
বন্ধ করতে Vercel-এ `DEMO_DATA=0`, পুরোপুরি মুছতে একবার `DEMO_DATA=remove` দিয়ে Redeploy।

| কে | মোবাইল | পাসওয়ার্ড / লগইন |
|---|---|---|
| ডা. তানভীর আহমেদ (হৃদরোগ, রাজশাহী) | 01700000001 | demo1234 |
| ডা. নুসরাত জাহান (দন্ত, রাজশাহী) | 01700000002 | demo1234 |
| ডা. রাশেদ করিম (শিশু, রাজশাহী + নাটোর) | 01700000003 | demo1234 |
| ডা. সাবরিনা হক (গাইনি, ঢাকা) | 01700000004 | demo1234 |
| অ্যাসিস্ট্যান্ট — ডা. তানভীর | 01700000011 | demo1234 |
| অ্যাসিস্ট্যান্ট — ডা. নুসরাত | 01700000012 | demo1234 |
| রোগী রহিম উদ্দিন (মা ও ছেলেসহ) | 01800000001 | /me/login → OTP |

রোগীর OTP: `SMS_PROVIDER` "http" না হলে কোডটা স্ক্রিনেই দেখায় (ডেমো মোড)। আসল এসএমএস গেটওয়ে চালু করলে কোড শুধু এসএমএসে যাবে।

## মূল নিয়মগুলো কোথায়

- **সিরিয়াল** (`src/lib/booking.ts`): প্রতি চেম্বারে প্রতিদিন ১ থেকে; কোড `RAJ-1102-07`; চেম্বারের রো লক করে নাম্বার দেওয়া হয়, তাই একসাথে ২০ জন বুক করলেও কেউ একই নাম্বার পায় না। অনলাইন সিরিয়াল দৈনিক লিমিটের নির্দিষ্ট % পর্যন্ত; সরাসরি আসা রোগী সবসময় যোগ করা যায়।
- **রোগী চেনা**: মোবাইল নাম্বার = অ্যাকাউন্ট; নিচে পরিবারের একাধিক রোগী; নাম্বার+নাম মিললে একই প্রোফাইল। প্রতিটি রোগীর স্থায়ী আইডি `P-10001`। স্টাফ শুধু নিজের ডাক্তারের রোগী খুঁজে পান।
- **লাইভ সময়** (`src/lib/queue.ts`): আজ পরপর দুই "সম্পন্ন"-এর মাঝের সময়ের গড় (শেষ ৮টা, ১–৬০ মিনিটের বাইরের ফাঁক বাদ); না থাকলে চেম্বার সেটিংয়ের গড়। আনুমানিক সময় = আগে কতজন × গড়।
- **ফলোআপ** (`src/lib/followup.ts`): প্রেসক্রিপশনে দিন বাছলে ফলোআপ তৈরি; প্রতিদিন রাত ৮টায় (ঢাকা) কালকের রোগীদের রিমাইন্ডার; তারিখ পেরোলে MISSED; রোগী ওই ডাক্তারের কাছে বুক করলে নিজে থেকে BOOKED ও ভিজিট "ফলোআপ"।
- **মেসেজ** (`src/lib/notify.ts`): সব মেসেজ `message_logs`-এ — মাসে কত এসএমএস গেল সেটা প্যাকেজের হিসাবে লাগবে। আসল গেটওয়ে যুক্ত করতে `sendHttpSms()` আপনার প্রোভাইডারের API অনুযায়ী মিলিয়ে নিন।

## অনলাইনে টেস্ট (ডোমেইন ছাড়া, ফ্রি)

1. GitHub-এ কোড তুলুন
2. [Neon](https://neon.tech) বা Supabase-এ ফ্রি PostgreSQL খুলে `DATABASE_URL` নিন (টেবিল তৈরি হয় প্রতিবার বিল্ডের সময় নিজে থেকেই — `npm run build` আগে migration চালায়)
3. [Vercel](https://vercel.com)-এ প্রজেক্ট ইমপোর্ট করে `.env.example`-এর ভ্যারিয়েবলগুলো বসান — `vercel.json`-এর cron নিজে চালু হবে
4. `xyz.vercel.app` লিংক ডাক্তারদের পাঠিয়ে পাইলট করুন

## পরের ধাপে যা বাকি

- bKash/Nagad অগ্রিম পেমেন্ট ও ডাক্তারের সাবস্ক্রিপশন
- রোগীর টেস্ট রিপোর্ট আপলোড (ফাইল স্টোরেজ)
- React Native অ্যাপ + পুশ নোটিফিকেশন (Firebase), হোয়াটসঅ্যাপ মেসেজ
- সুপার অ্যাডমিন প্যানেল (BMDC যাচাই, সাবস্ক্রিপশন)
- ডাক্তারের প্রোফাইল ছবি (ফাইল স্টোরেজ লাগবে), প্রেসক্রিপশন টেমপ্লেট
- সার্ভার ছাড়াও চলার জন্য অফলাইন মোড, আর লাইভ আপডেটের জন্য পোলিংয়ের বদলে SSE/WebSocket (বড় পরিসরে)

> QR কোড, পোস্টার ও প্রেসক্রিপশন প্যাডের লিংক `APP_URL` থেকে আসে — প্রিন্ট করার আগে নিশ্চিত হোন এটা আপনার আসল সাইটের ঠিকানা।
